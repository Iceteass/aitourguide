# 여행이 역사가 되는 순간 — UX/FD v1.1 (iPhone·Android PWA)

**기준은 사용자 제공 `history_travel_ux_design_v1_1(3).zip`의 v1.1 기능정의서입니다. v1.2 시안 및 확장 기능은 반영하지 않았습니다.**

## 실제 사용 주소

https://iceteass.github.io/kyoto-history-guide/

GitHub Pages 배포 완료 후 iPhone Safari / Android Chrome에서 접속하고 **홈 화면에 추가**합니다.

## 화면 흐름

1. **첫 화면**: 푸른 도로 + 「계속하려면 화면을 터치하세요」 한 줄
2. **국가 선택**: 같은 도로 배경에서 **일본**만 표시
3. **도시 선택**: 일본 전용 배경으로 바뀌고 **교토**만 표시
4. **여행지 선택**: **후시미 이나리 신사** 한 곳만 표시 / 여행지 열기 / 통합 다운로드·삭제
5. **관람 지도**: 기존 `route-map.jpg`와 1–7 장소 위치 유지. **이 단계를 건너뛰지 않음**
6. **장소별 해설**: 상단 사진 / 가운데 원고(독립 스크롤) / 하단 고정 MP3 플레이어
7. **다운로드·삭제 확인**: 여행지 단위 데이터 확인·검증·삭제

기존 7개 해설 원고, 전체 관람 지도, 7개 MP3, TTS 및 사용자 직접 등록 사진 기능은 유지합니다.

## 배경 이미지 원본 등록 필요 (2개)

현재 GitHub에는 독립 화면의 기능과 **SVG 대체 배경**을 등록했습니다. 사용자가 첨부한 v1.1의 **정확한 사진 배경**을 적용하려면 아래 원본 이미지 두 개를 GitHub 저장소의 `assets/` 폴더에 추가해야 합니다.

- `assets/road_green_drive.jpg` — 시작·국가 선택에서 동일하게 사용
- `assets/japan_kyoto_sunset.webp` — 일본 국가 선택 후 도시·여행지 선택에서 사용

작업: GitHub → `assets` 폴더 → Add file → Upload files → 위 두 파일 선택 → Commit changes. 파일을 ZIP 상태로 올리면 안 됩니다. 해당 원본은 사용자 업로드 UX v1.1 ZIP의 `assets/` 아래에 있습니다.

원본 2개가 없어도 화면은 `road-fallback.svg` / `japan-fallback.svg`로 표시되어 빈 화면이 되지 않습니다.

## 온라인/오프라인

- 앱 공통 화면과 SVG 배경은 PWA 설치 후 오프라인 이용을 목표로 캐시합니다.
- 여행지를 다운로드하지 않았다면 인터넷 연결 상태에서 지도·해설을 사용합니다.
- 여행지 카드의 **↓ 다운로드**는 지도/누문 사진/7개 MP3/6개 Wikimedia 사진을 내려받고 완료 검증을 수행합니다.
- 완료 전에는 **저장 완료**라고 표시하지 않으며, 외부 사진이 다운로드되지 않으면 **일부 저장됨**으로 남고 재시도할 수 있습니다.
- 저장 완료 뒤 비행기 모드로 실행합니다. MP3는 제작 음원을 기본으로 사용하고 TTS는 보조 기능입니다.
- **✓ 저장됨** 버튼 재선택 → 삭제 확인 → **예, 삭제**는 해당 여행지에 저장한 파일을 제거합니다. 국가·도시·여행지 목록, 앱 공통 화면, 개인이 등록한 사진은 지우지 않습니다.
- 브라우저/OS가 사이트 데이터를 정리하면 오프라인 파일이 삭제될 수 있습니다.
- 사진 원본이 외부 Wikimedia 경로에 있기 때문에 일괄 사진 내려받기는 네트워크 및 해당 파일의 접근성에 영향을 받습니다.

## 주요 검증 항목

- S01의 터치 안내만 표시, S02에서도 **동일한 도로 배경**.
- 일본 선택 후 일본 전용 배경, 교토와 후시미 이나리 한 곳만 표시.
- 여행지 열기 → **기존 7개 지점 지도 반드시 표시** → 선택한 지점 음성/원고.
- 상단 사진·중단 원고 스크롤·하단 MP3 조작부 분리, 이전/다음 장소 및 재생/일시정지 확인.
- 다운로드 완료 전/후 온라인·비행기 모드 재실행, 삭제 확인, 취소/재시도 및 다른 화면·등록 사진 보존.
- iPhone Safari 홈 화면 앱과 Android Chrome 홈 화면 앱을 **각각 실기기 검증**.

**상태:** GitHub에 텍스트 소스는 반영했습니다. 정식 iPhone/Android 실기기 테스트는 아직 수행하지 않았으며, 배경 원본 사진 2개는 수동 업로드가 남았습니다.
