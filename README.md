# 여행이 역사가 되는 순간

iPhone Safari·Android Chrome에서 동일하게 사용할 수 있는 **설치형 오프라인 여행 해설 PWA**입니다.

**기준:** `HISTORY_JOURNEY_UX_v1.1_CHANGE_SPEC_MODULAR_PACKS_KO.md`의 CR-01~09. 이전에 별도 작성했던 v1.2 화면 시안은 적용하지 않았습니다.

## 실행 주소

https://iceteass.github.io/aitourguide/

저장소: https://github.com/Iceteass/aitourguide

위 주소는 현재 저장소명을 기준으로 한 GitHub Pages 경로입니다. 실제 Pages 설정과 배포 상태는 GitHub에서 별도로 확인해야 합니다. 이전 저장소 URL에서 저장한 오프라인 자료는 새 URL로 자동 이전되지 않을 수 있으므로, 새 주소에서 여행팩을 다시 다운로드하고 필요하면 홈 화면 앱을 다시 설치하세요.

GitHub Pages 업데이트 후 Safari 또는 Chrome에서 열어 홈 화면에 추가합니다. 설치 후 **일본 → 교토 → 후시미 이나리 신사 → 기존 관람 가이드 지도(7곳) → 장소 선택 및 MP3 해설** 순서로 이용합니다.

## v1.2에서 달라진 점

- 시작 화면: 선명한 **DOM 텍스트**로 「여행이 / 역사가 되는 순간」 및 보조 문구 출력. 시작·국가 선택은 **같은 도로 원본 이미지** 사용, 일본 선택 후 국가 배경 전환
- 여행지 목록: `data/catalog.json`에서 **검증·등록된 여행지만** 자동 표시
- 여행지 카드: **원형 다운로드 및 빨간 휴지통 아이콘 분리**, 저장 상태는 카드 텍스트로 표시
- 상세 해설: 상단 사진, 가운데 독립 스크롤 원고, 하단 약 **125~146 CSS px** 재생 바
- 제작 MP3 기본 사용, 맨 오른쪽 재생·일시정지, **±5초**, 글자 없는 처음부터 이동, 속도 선택 유지
- 원고 자동 스크롤은 MP3 재생 비율을 이용한 **근사 방식**입니다. 정확한 문단 동기화는 `cues.json`이 있어야 가능합니다. 사용자가 원고를 터치/스크롤하면 잠시 자동 이동을 중지합니다.
- 여행지별 다운로드·삭제 격리 및 완료 검증. 저장된 버전은 새 버전 저장 실패 시 보존합니다.

## 여행지 모듈 구조

```text
data/catalog.json                            # 공개 등록 여행지만 표시
travel-packs/JP/kyoto/fushimi-inari/
  pack.json                                  # pack_id / 버전 / 자산 목록
  route/route-map.jpg                        # 기존 원본 관람 지도 유지
  route/points.json                          # 7개 지점의 정규화 좌표
  cover.jpg
  spots/
    01-odotorii/
      poi.json
      narration.md
      images/main.jpg
      audio/ko-N1.mp3
    ... (총 7개 장소)
  LICENSES.md
app/v12.js                                   # 공통 화면·여행지 로딩·저장
app/v12.css                                  # 모바일 전체 화면·플레이어
authoring/validators/validate_pack.mjs      # 등록 전 구조·용량·해시 검증
```

다른 국가·도시·여행지 추가 시 **공통 HTML/JS를 복제하지 않습니다**. 위와 동일한 폴더로 콘텐츠를 만들고, 검증 후 `data/catalog.json`에 등록하기만 하면 자동으로 목록에 표시됩니다. 생성 절차는 [authoring/README.md](authoring/README.md)를 확인하세요.

### 공통 앱과 여행팩의 경계

표준 경로는 `travel-packs/{country_code}/{city_id}/{destination_slug}/`입니다. 현재 등록된 팩은 `JP/kyoto/fushimi-inari/` 하나이며, 확장 예시를 위한 빈 국가·도시·여행지 폴더는 만들지 않습니다.

| 위치 | 역할과 관리 규칙 |
|---|---|
| `index.html`, `app/`, `audio-player.js` | 공통 화면·지도·해설·플레이어. 여행지마다 복제하지 않음 |
| `manifest.webmanifest`, `sw.js`, `icon-*.png`, `assets/` | 공통 PWA·앱 셸·배경. 여행팩에 이동하지 않음 |
| `data/catalog.json` | 검증된 팩의 공개 등록 목록. 국가·도시 목록은 `published` 항목을 필터링하여 생성 |
| `travel-packs/JP/kyoto/fushimi-inari/` | 독립 배포 콘텐츠: 팩 메타데이터, 표지, 지도·좌표, 7개 장소의 원고·사진·음성, 라이선스 |
| `authoring/` | 수동 제작 안내와 Node.js 검증기. 자동 여행팩 생성기는 현재 없음 |
| `tests/`, `.github/workflows/` | 회귀 검사와 CI. 현재 CI의 여행팩 검증 대상은 후시미 이나리 경로로 고정 |
| 여행지 미디어와 이전 v1.1 정적 파일 | 루트 중복 9개와 v1.1 JS/CSS는 v1.2.5에서 삭제. 콘텐츠는 팩 내부에서 관리하며 개인 사진/설정/현재 팩 캐시 호환은 유지 |

신규 팩은 다음 규칙으로 추가합니다.

1. 표준 경로 안에 기존 스키마(`schema_version: "1.0.0"`)와 같은 `pack.json`, `route/`, `spots/`, `LICENSES.md`를 작성합니다. 별도 국가·도시 JSON이나 공통 앱 사본은 만들지 않습니다.
2. catalog의 `path`·`cover`는 **앱 기준**, pack의 `cover`·`route`·`spots[].dir`·`spots[].meta`·`files[].path`는 **팩 기준**, POI의 원고·사진·음성 경로는 **해당 spot 기준**입니다. 팩 밖 파일이나 다른 팩을 공유 참조하지 않습니다.
3. catalog와 pack의 `pack_id`, `pack_version`, 국가·도시 값 및 `poi_count`를 일치시키고, `spots[].dir`와 `meta`의 폴더도 일치시킵니다. 기존 팩의 경로·ID·버전은 단순 정리를 위해 변경하지 않습니다. `audio.original_name`은 출처 기록이며 로딩 경로가 아닙니다.
4. 오프라인에 필요한 지도·좌표·POI JSON·원고·이미지·MP3·표지를 `files`에 등록하고 실제 바이트 크기와 가능한 SHA-256을 기록합니다. 검증기를 실행한 뒤 catalog의 `published`에 등록합니다. 신규 팩 검증을 CI 대상으로 추가하는 것도 별도로 확인합니다.

파일별 유지 근거, 중복 해시 확인, 캐시 의존성과 승인 후 수행할 후속 작업은 [여행팩 구조 조사](docs/travel-pack-audit.md)를 참고하세요. 이 조사는 이전 기준의 기록이며, 현재 앱 버전은 `app/version.js`에서 관리합니다.

## 비행기 모드 테스트

1. Wi-Fi 연결 후 사이트 최신 버전 새로고침. 기존 홈 화면 앱이면 완전히 종료했다가 다시 실행합니다.
2. 일본 → 교토 → 후시미 이나리 신사 목록에서 **동그란 다운로드 아이콘**을 누르고 확인합니다.
3. MP3 7개와 지도·원고·이미지가 모두 저장된 다음에만 **「오프라인 저장 완료」**가 표시됩니다. 사진 6곳의 로컬 참고 이미지는 지도 일러스트이며 실사 사진이 아닙니다.
4. 비행기 모드와 Wi-Fi 끄기 → 앱 완전 종료 → 홈 화면 앱 재실행 → 관람 지도 7개 핀 → MP3 재생 및 ±5초 확인.
5. 저장 자료를 제거하려면 빨간 휴지통을 누르고 확인창에서 삭제합니다. 다른 여행지와 공통 앱·사용자 개인 사진은 삭제하지 않습니다.
6. 모바일 OS가 사이트 데이터를 정리하면 다시 온라인으로 다운로드해야 할 수 있습니다.

## 주의

- 후시미 이나리 전용 지도·사진·MP3·원고는 팩 내부에서만 관리합니다. 루트 중복 및 v1.1 정적 JS/CSS는 삭제했으며, 현재 앱의 개인 사진·설정·완료 팩 캐시는 유지합니다. [지원 종료 및 업데이트 영향](docs/pack-independence.md)을 확인하세요.
- 기존 **누문 실사 사진**은 오프라인 제공됩니다. 다른 6개 장소는 온라인 Wikimedia 사진을 불러올 수 있으나 오프라인에서는 **기존 관람 지도 일러스트**로 대체됩니다. 실제 사진 교체에는 권리 확인과 폴더 업데이트가 필요합니다.
- 배경은 `assets/manifest.json`의 기본 항목과 `assets/app/`·`assets/countries/`의 정식 경로를 사용합니다. 기존 파일은 구 설치 호환 사본으로 유지하며 제목은 DOM 텍스트입니다. 변경·업로드 절차는 [공통 자산 계약](docs/common-assets.md)을 따릅니다.
- iPhone과 Android 실기기 재생·화면 잠금 중 재생은 별도 검증이 필요합니다. 본 저장소의 문법·데이터 검증 성공이 실기기 성공을 의미하지는 않습니다.

## v1.2.2 — 문장 읽기 동기화 및 MP3/TTS 자동 선택

- **MP3:** 실제 음성과 어긋나는 재생 비율 기반 원고 자동 스크롤을 제거했습니다. 문장별 정확한 타이밍 정보(cues)가 없을 때는 원고를 직접 스크롤합니다.
- **TTS:** SpeechSynthesisUtterance.onstart에서 현재 문장을 강조합니다. 이전 문장의 onend 이후 다음 문장이 시작될 때만 스크롤을 이동합니다. 사용자가 스크롤하면 잠시 자동 이동을 제한합니다.
- **자동 선택:** 해당 장소의 MP3가 완료 표시를 가진 여행지 오프라인 캐시에 저장되고 바이트 크기 검증을 통과할 때만 제작 MP3가 기본입니다. 그렇지 않으면 기기 TTS가 기본입니다.
- **오류 전환:** 저장된 MP3도 실제 재생 실패/로드 실패 시 TTS로 전환합니다. 상세 화면 진입 시 자동 재생하지 않고 ▶를 눌러 시작합니다.
- **주의:** 기기에 오프라인 한국어 TTS 음성이 없으면 비행기 모드에서 TTS가 작동하지 않을 수 있습니다. 기존 관람 지도, MP3 7개, 원고 및 여행지 폴더 구조는 유지됩니다.

회귀 검증: tests/validate_mp3_runtime.mjs, tests/validate_narration_sync.mjs, tests/validate_v121.mjs, 여행팩 검증.


## v1.2.3 — 앱 버전 표시 및 관리

첫 화면의 기존 터치 안내 아래에 작은 `App vX.Y.Z`를 표시합니다. 단일 버전 원본은 `app/version.js`이며 문서 제목과 오프라인 앱 셸도 같은 값을 사용합니다. 기존 여행팩 v1.2.0, 스키마 1.0.0 및 저장 데이터는 유지합니다.

[앱·여행팩 버전 관리 및 Commit/PR/Tag/Release 절차](docs/versioning.md)와 [4단계 통합 개발 계획](docs/development-plan.md)을 참고하세요. 이번 단계는 버전 표시만 구현하며 Creator·Publisher 및 전체 팩 CI는 후속 PR 범위입니다. 다음 단계는 현재 PR 검토·병합 후 최신 main에서 시작합니다.


## v1.2.4 — 공통 이미지 체계와 기존 앱 검증

`assets/app/{splash,backgrounds,fallbacks}/`와 `assets/countries/JP/images/`에 기존 이미지와 같은 바이트의 정식 사본을 배치했습니다. 기존 URL·아이콘·루트 레거시·여행팩은 유지합니다. manifest가 현재 화면의 기본 배경과 fallback을 결정하며, 미등록 국가·도시는 일반/국가 기본 배경으로 표시됩니다. 계절 자동 전환·배경 선택 UI는 없습니다.

[공통 이미지 규격·변경 전후·파일별 유지/보류 판단](docs/common-assets.md)과 [향후 Creator/Publisher 통합 계약 및 수동 등록](docs/travel-pack-integration.md)을 확인하세요. Creator·Publisher·전체 팩 CI는 별도 개발/통합 범위이며 이번에는 기존 앱 검증과 자산 Node 검사만 추가했습니다.


## v1.2.5 — 여행팩 완전 독립화

여행지 전용 루트 지도·사진·MP3 9개와 v1.1 정적 JS/CSS를 실제 삭제했습니다. 지도·표지는 선택한 팩 메타데이터로 해석하고 데이터가 없으면 공통 fallback을 사용합니다. 미다운로드 팩의 오프라인 진입은 허용하지 않습니다. 기존 v1.2.3/v1.2.4 업데이트·사진 숫자 키·새 키·설정·팩 캐시를 검증했습니다. 상세 삭제 목록·경로·검사 및 미검증 범위는 [완전 독립화 보고서](docs/pack-independence.md)를 참고하세요.
