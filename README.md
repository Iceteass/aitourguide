# 교토 역사 해설 가이드 · iPhone + Android 공용 PWA

후시미 이나리 관람 지도와 7개 장소의 역사 해설을 한 코드로 제공하는 **설치형 웹 앱(PWA)** 입니다. 기존 v1.7의 지도/설명/음성/사진 기능을 유지하고 모바일 앱 아이콘과 오프라인 캐시를 추가했습니다.

## 1. GitHub Pages 활성화

프로젝트: https://github.com/Iceteass/kyoto-history-guide

- 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
- GitHub Free에서 저장소가 Private이라면 Pages를 게시할 수 없습니다. 무료로 게시하려면 **Settings → General → Danger Zone → Change repository visibility → Public**으로 변경하세요. 공개 전에 코드/사진/자료의 공개 가능 여부를 확인하세요.
- 게시가 완료되면 아래 주소에서 접속합니다.

**웹 앱 주소:** https://iceteass.github.io/kyoto-history-guide/

> 페이지가 공개되기 전에는 이 주소가 열리지 않을 수 있습니다. Public으로 전환해도 Pages가 자동으로 활성화되는 것은 아닙니다.

## 2. iPhone 설치 (Safari)

1. Safari에서 위 **웹 앱 주소**를 열고 지도 아래에 **오프라인 지도/해설 준비 완료**가 표시되는지 확인합니다.
2. Safari 공유 → **홈 화면에 추가** → 가능하면 **웹 앱으로 열기** 켜기 → 추가.
3. 홈 화면 **교토 해설** 아이콘 실행 → 장소 1~7, 화면 이동, 전체 해설, 음성, 사진을 확인합니다.
4. Wi-Fi/셀룰러를 끄고 홈 화면 아이콘으로 다시 실행하여 지도·텍스트가 열리는지 확인합니다.

## 3. Android 설치 (Chrome)

1. Chrome에서 위 **웹 앱 주소**를 열고 오프라인 준비 문구를 확인합니다.
2. 우측 상단 **⋮ → 앱 설치** 또는 **홈 화면에 추가** → 설치.
3. 홈 화면 아이콘으로 실행 → 장소 1~7, 전체 해설, 한국어 TTS, 사진을 확인합니다.
4. 비행기 모드로 전환해 앱을 다시 실행하고 지도·텍스트를 확인합니다.

## 4. 공통 테스트 항목

| 항목 | iPhone | Android |
| --- | --- | --- |
| 7개 장소 지도·원고 오프라인 | 확인 필요 | 확인 필요 |
| 홈 화면 독립 실행 | 확인 필요 | 확인 필요 |
| 한국어 TTS/음성 선택/재생 속도 | 확인 필요 | 확인 필요 |
| 장문 해설 연속재생·일시정지 | 확인 필요 | 확인 필요 |
| 사진 저장 후 앱 재실행 | 확인 필요 | 확인 필요 |

**TTS 주의:** 운영체제의 한국어 음성/엔진 설치 상황에 따라 달라지며, 백그라운드·화면잠금 상태에서 연속 재생은 보장되지 않습니다.

**사진 주의:** 누문 참고 사진과 지도는 오프라인 내장되어 있으나, 나머지 장소의 Wikimedia 사진은 온라인이며 오프라인에서는 지도 이미지로 대체될 수 있습니다. 기기에 따로 저장한 사진은 브라우저 저장 데이터 삭제 시 소실될 수 있습니다.

## 5. 파일 설명

- `index.html`: 가이드 화면 및 7개 장소의 원고·TTS·사진 인터페이스
- `sw.js`: 기본 지도/원고/아이콘/누문 이미지의 오프라인 캐시
- `manifest.webmanifest`: 공용 앱 이름·설치 아이콘·시작 경로
- `route-map.jpg`, `romon-preview.jpg`: 오프라인 이미지
- `icon-192.png`, `icon-512.png`: 홈 화면 아이콘

웹 앱 버전: **v1.7.1**. 업데이트 후 이전 내용이 보이면 온라인 상태에서 새로고침하거나 홈 화면 앱을 종료 후 다시 실행해 주세요.

이 패키지의 코드는 정적 점검되었지만 **iPhone 및 Android 실기기에서의 실행 성공을 아직 확인한 것은 아닙니다**.
